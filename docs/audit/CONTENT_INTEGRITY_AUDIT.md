## 2. Inconsistent Claims & Counter Discrepancies

1. **Card Counts vs Reality:**
   In `src/pages/Library.jsx`:
   - Atharvaveda card claims: `"730 Suktas"` (Traditional canonical total). The repository actually contains **5 Suktas**.
   - Rigveda card claims: `"1,028 Suktas"`. The repository contains **3 Suktas**.
   - Samaveda card claims: `"1,875 Mantras"`. The repository contains **0 Suktas** in the UI.
   - Yajurveda card claims: `"1,975 Shlokas"`. The repository contains **0 Suktas** in the UI.
   *Problem:* Presenting traditional canon totals as though they are browseable archive contents is misleading to seekers.

2. **Reader Fallback Behavior (`src/pages/VerseDetail.jsx`):**
   - Line 53: `const canonicalVerse = CANONICAL_VERSES.find(v => v.ref === ...) || CANONICAL_VERSES[0];`
   - If a user navigates to any verse other than `1.1.1`, `12.1.1`, or `19.9.1`, the reader silently defaults to rendering verse `1.1.1` (*Ye triṣaptāḥ pariyanti...*), falsely claiming it is the requested reference!

3. **Fabricated Recitation & Pitch Scoring:**
   - In `VerseDetail.jsx:75`:
     ```javascript
     const handleSingAlong = () => {
       ...
       setPitchScore(Math.floor(82 + Math.random() * 15));
     };
     ```
   - Clicking "Chant on Pitch" or "Sing Along" generates a pseudo-random integer between 82 and 97 using `Math.random()`.
   - *Problem:* Violates non-negotiable safety rules: *"Do not claim that a pitch score or recitation evaluation is accurate unless its method and reference data are validated."*

4. **Fabricated Default User Progress:**
   - In `src/store/useGameStore.js`:
     A freshly created user account initializes with `versesMastered: 14`, `streak: 3`, `quizzesWon: 8`, `mantrasRecited: 36`, and `rp: 120`.
   - *Problem:* Fabricates learning history before the user has performed any learning event.

## 3. Recommended Content Taxonomy

Every passage rendered in the application must carry an explicit status tag:

| Status Key | Definition | UI Treatment |
| :--- | :--- | :--- |
| `verified` | Text, meter, swara accents, and translation reviewed by a qualified Sanskrit scholar. | Discreet moonlit badge with scholarly citation. |
| `needs_review` | Canonical text from standard editions (e.g. Whitney, Bloomfield, Saunaka Shakha) awaiting scholarly sign-off. | Neutral status: *"Scholarly Review Pending"*. |
| `unverified` | Sourced from open digital archives without validated accent markings. | Clarifying note: *"Unverified digital transcription"*. |
| `generated` | Dynamic translations, commentary, or philosophical reflections created by AI (Gemini). | Visibly separated from canonical Sanskrit text; labeled *"AI-Assisted Interpretation"*. |
| `unavailable` | Passages referenced but not yet transcribed in the digital archive. | Honest empty state: *"Passage not yet indexed in digital archive. Contributions welcome."* |
